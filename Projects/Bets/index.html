Sports Betting Management System

Python Flask SQLite OOP CRUD

🎯 Project Overview

This web application allows users and managers to interact in a simulated sports betting environment. Managers can create and manage users, teams, events, and bets, while bettors can place and review their own bets. The system uses Flask for backend management and SQLite as a lightweight database solution.

⚙️ Key Features

  • User authentication with session management
  • Separate dashboards for Managers and Bettors
  • CRUD operations for Users, Teams, Events, and Bets
  • Dynamic data visualization with generated tables and graphs
  • Points system and sport ranking module

🧠 Technologies Used

  • Python (Flask framework)
  • SQLite database
  • HTML, CSS, Jinja templates
  • Matplotlib & Pandas (for charts and tables)
