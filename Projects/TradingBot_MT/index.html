Trading Robot Project

Description

This project is a Python-based trading robot that applies a "dip strategy" on stock data. It generates buy signals when the stock price drops 20% below the 365-day high, blocking new buys until the last maximum price is touched again. The bot performs a simple backtest using historical data from Yahoo Finance.

Technologies Used

  • Python
  • pandas (data analysis)
  • yfinance (historical stock data)
  • matplotlib (visualization)
